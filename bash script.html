Write into a log file
1: Overwrite (replace content)
echo "Hello Shawon" > shawon.log
2: Append (add new content, most common)
echo "New log entry" >> shawon.log

how to view file content in terminal
cat file_name
Copy content to another file
cat file1.txt > file2.txt

want to search any specific text (patterns) inside files or command output in Bash.
1: Basic example
grep "error" file_name
2: Find errors in a log file
grep "ERROR" app.log
3: Ignore case (error / Error / ERROR)
grep -i "error" app.log

count how many errors occurred
grep -c "error" shawon.log

Find log files updated within one day
1:
find . -name "*.log" -mtime -1
2: Show contents of recent log files
find . -name "*.log" -mtime -1 -exec cat {} \;

what is shell script

A shell script is a file that contains a sequence of commands written for a command-line interpreter (called a shell) such as Bash.

Instead of typing commands one by one in the terminal, you save them in a file and run them all together.
1: Example

#!/bin/bash

echo "Hello Shawon"
pwd
date

2: shell file like this to the end point
.sh
example
analyse-log.sh
